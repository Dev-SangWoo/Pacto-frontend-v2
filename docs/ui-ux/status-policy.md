# Pacto Status Policy

## 1. 문서 목적

이 문서는 Pacto MVP에서 사용하는 주요 상태값과 UI 표시 규칙을 정의한다.

상태값은 Pacto의 핵심이다. 캠페인, 지원, 미션, 정산, 출금 상태가 화면마다 다르게 표현되면 사용자는 돈의 흐름과 다음 행동을 이해하기 어렵다.

---

## 2. 상태 표시 원칙

```txt
상태는 텍스트만으로 표시하지 않고 배지로 표현한다.
상태 배지 문구는 화면 전체에서 동일하게 사용한다.
상태에 따라 가능한 액션을 제한한다.
돈과 관련된 상태는 특히 명확하게 표현한다.
```

---

## 3. Campaign 상태

| 상태 | 한글 표시 | 설명 | 주요 액션 |
| --- | --- | --- | --- |
| draft | 임시 저장 | 아직 공개되지 않은 캠페인 | 수정, 공개 |
| open | 모집 중 | 블로거 지원 가능 | 지원, 수정 |
| full | 모집 완료 | 모집 인원이 찬 상태 | 지원 불가 |
| closed | 마감 | 모집 기간이 끝난 상태 | 지원 불가 |
| completed | 완료 | 캠페인이 종료된 상태 | 리포트 확인 |
| cancelled | 취소 | 캠페인이 취소된 상태 | 정산/환불 확인 |

---

## 4. Application 상태

| 상태 | 한글 표시 | 설명 | 주요 액션 |
| --- | --- | --- | --- |
| pending | 승인 대기 | 블로거가 지원했고 대행사 검토 전 | 승인, 반려 |
| approved | 승인됨 | 대행사가 참여를 승인 | 미션 수행 |
| rejected | 반려됨 | 대행사가 지원을 반려 | 없음 |
| cancelled | 취소됨 | 지원이 취소됨 | 없음 |

---

## 5. Mission 상태

| 상태 | 한글 표시 | 설명 | 주요 액션 |
| --- | --- | --- | --- |
| not_started | 시작 전 | 승인됐지만 아직 미션을 시작하지 않음 | 미션 확인 |
| in_progress | 진행 중 | 미션 수행 중 | 제출 |
| submitted | 제출 완료 | 블로거가 제출했고 검수 전 | 승인, 반려 |
| approved | 승인됨 | 미션이 승인됨 | 정산 진행 |
| rejected | 반려됨 | 미션이 반려됨 | 재제출 또는 종료 |

---

## 6. Settlement 상태

| 상태 | 한글 표시 | 설명 | 주요 액션 |
| --- | --- | --- | --- |
| locked | 예치 중 | 금액이 에스크로에 잠겨 있음 | 상태 확인 |
| ready | 정산 가능 | 검수 완료 후 정산 가능한 상태 | 정산 실행 |
| paid | 정산 완료 | 블로거 지갑으로 정산 완료 | 내역 확인 |
| cancelled | 취소됨 | 정산이 취소됨 | 사유 확인 |

---

## 7. Withdrawal 상태

| 상태 | 한글 표시 | 설명 | 주요 액션 |
| --- | --- | --- | --- |
| requested | 신청됨 | 출금 신청 접수 | 취소 가능 여부 확인 |
| processing | 처리 중 | 출금 처리 중 | 대기 |
| completed | 완료 | 출금 완료 | 내역 확인 |
| failed | 실패 | 출금 실패 | 재신청 |
| cancelled | 취소됨 | 출금 신청 취소 | 없음 |

## 8. 버튼 활성화 규칙

## 8.1 캠페인 지원 버튼

| 조건 | 버튼 상태 |
| --- | --- |
| campaign.status = open | 지원 가능 |
| campaign.status = full | 비활성, 모집 완료 |
| campaign.status = closed | 비활성, 마감됨 |
| application.status = pending | 비활성, 지원 완료 |
| application.status = approved | 비활성, 참여 중 |

## 8.2 미션 제출 버튼

| 조건 | 버튼 상태 |
| --- | --- |
| mission.status = in_progress | 제출 가능 |
| mission.status = submitted | 비활성, 검수 중 |
| mission.status = approved | 비활성, 승인 완료 |
| mission.status = rejected | 재제출 가능 여부에 따라 결정 |

## 8.3 출금 신청 버튼

| 조건 | 버튼 상태 |
| --- | --- |
| availableBalance > 0 | 신청 가능 |
| availableBalance = 0 | 비활성 |
| withdrawal.processing 존재 | 추가 신청 제한 여부 검토 |

## 9. 금액 상태 표시 규칙

지갑 화면에서는 금액을 반드시 분리한다.

```txt
availableBalance: 출금 가능한 금액
lockedBalance: 검수 또는 정산 대기 중인 금액
totalEarned: 누적 수익
```

표시 규칙:

```txt
금액은 원화 기준으로 표시한다.
천 단위 구분자를 사용한다.
available과 locked는 같은 색으로 표현하지 않는다.
locked 금액에는 설명 tooltip 또는 helper text를 제공한다.
```

## 10. 상태 변경 로그

정산 관련 화면에는 상태 변경 로그를 표시하는 것을 권장한다.

예시:

```txt
2026-06-02 10:00 결제 완료
2026-06-02 10:01 에스크로 예치 완료
2026-06-04 14:20 미션 제출 완료
2026-06-05 09:30 미션 승인
2026-06-05 09:31 정산 완료
```
