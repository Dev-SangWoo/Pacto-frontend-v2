# 출금 신청(환전)

Dev Test: 시작 전
Local Test: 시작 전
Method: POST
URL: /api/v1/wallets/withdraw
담당: 승환 양
도메인: Wallet

## 설명

<aside>
📌

블로거가 자신의 가용 잔액(`balance`)을 실제 현금으로 환전하기 위해 출금을 요청하는 API입니다.

요청 즉시 블로거의 지갑 잔액(`balance`)이 차감되며, DB에 출금 요청 내역(상태: `PENDING`)이 기록됩니다. (MVP 단계에서는 관리자가 해당 내역을 확인 후 매주 정해진 요일에 수동으로 실제 계좌 송금 처리를 진행합니다.)

</aside>

✅ **201 Created**

</aside>

```json
{
  "success": true,
  "message": "출금 신청이 정상적으로 접수되었습니다.",
  "data": {
    "withdrawalId": 77,
    "requestedAmount": 50000,
    "remainingBalance": 30000,
    "status": "PENDING"
  }
}
```

<aside>
❌ **409 Conflict → 잔액부족**

</aside>

```json
{
  "success": false,
  "message": "지갑의 출금 가능 잔액이 부족합니다.",
  "data": null
}
```

<aside>
❌ **400 Bad Request → 최소 금액 / 입력값 오류**

</aside>

```json
{
  "success": false,
  "message": "최소 출금 가능 금액은 10,000원입니다.",
  "data": null
}
```
