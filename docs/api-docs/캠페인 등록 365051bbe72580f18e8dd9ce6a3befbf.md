# 캠페인 등록

Dev Test: 시작 전
Local Test: 시작 전
Method: POST
URL: /api/v1/campaigns
담당: 장지연
도메인: Campaign

## 설명

<aside>
📌

광고주가 새 캠페인을 등록합니다.

등록 시점에 BE1 원장 API를 호출하여 광고주 wallet의 balance를 locked_balance로 이동시킵니다. 잔액 부족 시 400을 반환합니다.

</aside>
