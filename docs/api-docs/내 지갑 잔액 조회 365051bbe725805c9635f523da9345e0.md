# 내 지갑 잔액 조회

Dev Test: 시작 전
Local Test: 시작 전
Method: GET
URL: /api/v1/wallets/me
담당: 승환 양
도메인: Wallet

## 설명

<aside>
📌

현재 로그인한 사용자의 가용 잔액(`balance`)과 에스크로에 묶여있는 잔액(`locked_balance`)을 동시에 조회하는 API입니다.

광고주는 새로운 캠페인을 오픈할 수 있는 여유 자금을 확인하거나 에스크로 진행 현황을 파악할 때 사용하며, 블로거는 정산이 완료되어 실제 출금이 가능한 포인트를 확인할 때 호출합니다. 앱 내 상단 헤더나 마이페이지 등 잔액 정보가 필요한 모든 화면에서 공통으로 사용됩니다.

</aside>
