# 미션 승인

Dev Test: 시작 전
Local Test: 시작 전
Method: PATCH
URL: /api/v1/missions/{missionId}/approve
담당: 장지연
도메인: Mission

## 설명

<aside>
📌

광고주가 블로거의 제출물을 확인 후 미션을 승인합니다.

승인 즉시 BE1 정산 API가 트리거되어 escrow_ledger 상태가 RELEASED로 변경되고 블로거 지갑 balance가 증가합니다. SUBMITTED 상태가 아닌 경우 400을 반환합니다.

</aside>
