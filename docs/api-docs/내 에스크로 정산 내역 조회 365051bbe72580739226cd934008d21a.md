## 설명

<aside>
📌

광고주가 예치한 금액 중, "어떤 캠페인의 어떤 블로거에게 얼마가 묶여있는지" 상세 내역(영수증)을 확인하는 API입니다.

광고주 대시보드나 예산 관리 페이지에서 진행 중인 캠페인의 자금 흐름을 투명하게 보여주기 위해 페이징(Pagination) 형태로 리스트를 반환합니다.

</aside>
