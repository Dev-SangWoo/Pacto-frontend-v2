# 결제 준비

Dev Test: 시작 전
Local Test: 시작 전
Method: POST
URL: /api/v1/payments
담당: 지원 황
도메인: Payment

## 설명

<aside>
📌

포트원 결제창을 띄우기 전 프론트가 서버에 내부 결제 객체 생성을 위해 요청합니다.

1. 서버가 Payment 생성
   merchantUid 발급
2. 프론트가 merchantUid로 포트원 결제 진행
3. 결제 완료 후 프론트가 서버에 merchantUid + impUid 전달로 검증 (/verify api)
4. 서버가 포트원에 impUid 조회
5. 금액/상태/주문번호가 맞으면 status = PAID

순서대로 진행됩니다.

</aside>
