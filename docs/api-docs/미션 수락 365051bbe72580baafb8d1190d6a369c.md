# 미션 수락

Dev Test: 시작 전
Local Test: 시작 전
Method: POST
URL: /api/v1/campaigns/{campaignId}/missions
담당: 장지연
도메인: Mission

## 설명

<aside>
📌

블로거가 캠페인 미션을 선착순으로 수락합니다.

성공 시 missions 레코드 생성 및 BE1에 escrow LOCK을 요청합니다. Redis 분산 락으로 동시성을 제어하며, 락 획득 실패 시 503을 반환합니다.

</aside>
