# 포인트 변동 내역 조회

Dev Test: 시작 전
Local Test: 시작 전
Method: GET
URL: /api/v1/wallets/me/histories
담당: 승환 양
도메인: Wallet

## 설명

<aside>
📌

사용자의 지갑에서 발생한 모든 자금의 흐름(포트원 충전, 에스크로 예치, 정산 완료, 환불 등)을 시간순으로 조회하는 API입니다.

1원이라도 잔액이 변동된 기록은 모두 이 API를 통해 페이징(Pagination) 형태로 제공되며, 사용자가 "내 포인트가 왜 차감/증가되었는지" 투명하게 확인할 수 있도록 마이페이지의 '포인트 내역' 화면에 리스트 형태로 뿌려주는 용도로 사용합니다.

`CHARGE` : 포트원 결제로 지갑 충전
`LOCK` : 캠페인/미션 진행을 위해 에스크로로 잠금
`RELEASE` : 미션 승인 후 블로거 지갑으로 정산
`REFUND` : 취소/반려로 잠금 금액 환불
`WITHDRAW` : 출금 신청으로 잔액 차감

</aside>

## 설명

<aside>
📌

블로거가 자신의 가용 잔액(`balance`)을 실제 현금으로 환전하기 위해 출금을 요청하는 API입니다.

요청 즉시 블로거의 지갑 잔액(`balance`)이 차감되며, DB에 출금 요청 내역(상태: `PENDING`)이 기록됩니다. (MVP 단계에서는 관리자가 해당 내역을 확인 후 매주 정해진 요일에 수동으로 실제 계좌 송금 처리를 진행합니다.)

</aside>
